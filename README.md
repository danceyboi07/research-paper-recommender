## Why I Built This

I built this project because I was spending a lot of time searching for
papers related to machine learning and neuroscience research, and I
wanted to see if there was a better way to explore related work.

The project started as a simple semantic paper recommender and gradually
expanded into a system with personalized ranking and an interactive 3D
research map. From my own informal testing, using the tool made exploring
related papers roughly 5x faster than my previous manual search process.
There's a Google Colab Demo in the repo if you want to try it out.

I used AI coding tools throughout development to help prototype ideas,
debug issues, and learn unfamiliar technologies. I made the architectural
decisions, iterated on the code's logic, tested the system, and
adapted the code as the project evolved.
